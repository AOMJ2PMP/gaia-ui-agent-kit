# File Preview

Display uploaded files with smart type detection, file icons, image thumbnails, and upload progress.

## When To Use

Attached file chips, upload states, and document/image previews.

## Install

```bash
npx shadcn@latest add https://ui.heygaia.io/r/file-preview.json
```
